## ✨ Возможности

### 🔴 Полная блокировка
- **Блокировка сайта** — все домены MAX перенаправляются на localhost
- **Блокировка приложения** — запрет на запуск десктопного клиента через реестр Windows
- **Блокировка установщика** — невозможность установить или обновить MAX
- **Мгновенное применение** — изменения вступают в силу сразу после нажатия кнопки

### ⚙️ Расширенные настройки приватности
Выберите, какие функции MAX заблокировать:

| Функция | Что блокируется |
|---------|----------------|
| 📷 **Камера** | Видеозвонки, WebRTC, доступ к веб-камере |
| 🎙️ **Микрофон** | Аудиозвонки, запись звука, голосовые сообщения |
| 📇 **Контакты** | Доступ к адресной книге и списку контактов |
| 🔔 **Push-уведомления** | Уведомления, аналитика, телеметрия |

✅ **Двойная защита** — ограничения работают одновременно для:
- Браузерной версии (через файл hosts)
- Десктопного приложения (через реестр Windows)

### 🖥️ Удобная работа
- **Фоновый режим** — программа работает в системном трее
- **Автозагрузка** — автоматический старт при запуске Windows
- **Single Instance** — защита от запуска нескольких копий
- **Уведомления** — понятные сообщения о всех действиях

## 📥 Установка

### Быстрый старт

1. **Скачайте последнюю версию** из раздела [Releases](https://github.com/TheBefridi/Zapret-Messenger-MAX/releases/tag/MAX)
2. **Запустите от имени администратора** (обязательно!)
   - ПКМ по файлу → "Запуск от имени администратора"
3. **Готово!** Программа готова к работе
