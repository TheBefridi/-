## ✨ Возможности

### 🔴 Полная и надежная блокировка
- **Блокировка сайта** — все домены MAX перенаправляются на локальный адрес.
- **Блокировка приложения** — запрет на запуск десктопного клиента через реестр Windows (IFEO).
- **Блокировка установщика** — невозможность установить или обновить MAX.
- **Мгновенное применение** — изменения вступают в силу сразу после нажатия кнопки с автоматической очисткой DNS-кэша.

### 🖥️ Удобная и безопасная работа
- **🔄 Автоматические обновления** — программа сама проверяет наличие новой версии при запуске и предлагает обновиться в один клик.
- **Фоновый режим** — программа работает в системном трее, не мешая работе.
- **Автозагрузка** — автоматический старт при запуске Windows (с уведомлением только при ручном изменении настройки).
- **Single Instance** — защита от запуска нескольких копий программы одновременно.
- **Безопасный выход** — при полном закрытии программы блокировка автоматически снимается, чтобы не оставлять систему в непредсказуемом состоянии.

## 📥 Установка

### Быстрый старт
1. Перейдите в раздел **[Releases](https://github.com/TheBefridi/Zapret-Messenger-MAX/releases)** этого репозитория.
2. Скачайте последнюю версию файла `ZapretMessengerMAX.exe` (из раздела Assets).
3. Нажмите на файл **правой кнопкой мыши** и выберите **«Запуск от имени администратора»** (это обязательно для работы с файлом hosts и реестром).
4. Нажмите большую зеленую кнопку **«Заблокировать»**.
5. Готово! При необходимости обновите страницу в браузере (Ctrl + F5).

## 📜 История изменений (Changelog)

### 🚀 Версия 0.0.2 (Актуальная)
**Фокус на стабильность, удобство и надежность.**

- ✨ **Новое:** Встроена система автоматической проверки обновлений через GitHub Pages.
- ✨ **Новое:** Добавлен индикатор текущей версии программы в нижнем углу главного окна.
- 🛠️ **Исправлено:** Устранен критический вылет программы при нажатии кнопки "Обновить позже".
- 🛠️ **Исправлено:** Убрано назойливое всплывающее окно об автозагрузке при старте программы (теперь уведомление появляется только при ручном изменении галочки).
- 🛠️ **Исправлено:** Улучшена логика очистки DNS-кэша и завершения фоновых процессов для 100% срабатывания блокировки.
- 🗑️ **Удалено:** Раздел "Расширенные настройки приватности". *Причина:* Попытки программно менять глобальные политики Windows приводили к блокировке камеры/микрофона для ВСЕХ приложений в системе. Программа теперь фокусируется исключительно на своей главной задаче — надежной блокировке MAX, не ломая настройки Windows.

### 🔹 Версия 0.0.1 (Demo)
- 🎉 Первоначальный релиз программы.
- Базовая блокировка через файл `hosts` и реестр Windows (IFEO).
